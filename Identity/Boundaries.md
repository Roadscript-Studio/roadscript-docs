# Roadscript™ Boundaries
## We will NOT:
- sell physical goods
- resell third-party products
- chase algorithm-driven content formats
- release features without a clear creator pain point
- build for “everyone”

## We may consider:
- digital-only assets
- tools that reduce creator anxiety
- products that can be maintained by one person

## We will stop a project if:
- it requires constant manual support
- it increases brand noise
- it forces premature scaling

## Boundary Enforcement
If a project violates any rule above, it must be paused or removed,
even if it is profitable or popular.
